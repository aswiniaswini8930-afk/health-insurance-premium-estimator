# Health Insurance Premium Estimator

A machine learning web application built using Python and Streamlit to estimate health insurance premiums.

## Features
- Interactive input form
- Saved machine learning model
- Data preprocessing using a saved scaler
- Premium prediction display

## Technologies
- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit

## Run Locally

1. Install the dependencies:

   `pip install -r requirements.txt`

2. Start the application:

   `streamlit run app.py`

## Project Files
- `app.py` — Streamlit dashboard
- `insurance_bundle.pkl` — Saved model, scaler, and feature information
- `requirements.txt` — Required Python packages

## Note
Predictions are estimates and are not official insurance quotes.
